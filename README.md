# CMU SpringBoard — Prototype

Clickable UI prototype of **CMU SpringBoard**, a part-time job marketplace for students of
CMU School of Lifelong Education.

- Live: GitHub Pages (see the repository's About section)
- Full screen without the phone frame: add `#full` to the URL
- Single file: `index.html` (all images inlined)

All names, numbers and records in the prototype are sample data.
